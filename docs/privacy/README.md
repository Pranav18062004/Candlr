# Hosting the privacy policy

`index.html` is a static, offline-authored privacy policy. It makes no network requests and contains no analytics. The same text is available inside Candlr in Settings.

Before submitting to Google Play, publish this directory at a stable public HTTPS URL and open that URL without authentication to verify it. For example, GitHub Pages can serve the repository's `/docs` directory; if configured for this repository, the expected policy URL is `https://pranav18062004.github.io/Candlr/privacy/`. That URL is not claimed to be live: Pages has not been enabled by this task. Enter the verified live URL in Play Console.

If the support address changes, update both the public page and `privacy_body` / `developer_contact` in Android string resources, and update the Play listing. Current owner-approved address: pranavnambiar12345@gmail.com.
